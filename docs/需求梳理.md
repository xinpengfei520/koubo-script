# 卖点 → 30 秒口播稿 · 需求梳理 v0.1

> 场景：给一个卖点和人群，生成 30 秒口播 + 镜头提示  
> 产出：1 份分段口播稿 + 3 条镜头提示 + 1 份禁用词检查  
> 状态：M0 待确认

## 1. 一句话定义

输入「1 个卖点 + 1 个人群」，产出一条**能直接念、能直接拍、能直接过审**的 30 秒口播。

不是"写一段文案"，是"交一份可以开机的拍摄件"。

## 2. 谁在用，什么时候用

| 角色 | 使用时刻 | 现在的痛点 |
|---|---|---|
| 短视频运营 / 编导 | 拿到卖点，当天要出脚本 | 写出来像产品说明书，不像人说话 |
| 个体商家 / 店主 | 自己举着手机拍 | 一开口就超时，或者 15 秒就说完了 |
| 投放 / 审核 | 发布前把关 | 极限词、功效词肉眼扫不干净，发出去被限流 |

核心矛盾：**30 秒只装得下一件事**，但人的本能是想把卖点全说完。

## 3. 输入契约

### 3.1 必填

| 字段 | 说明 | 校验规则 |
|---|---|---|
| 卖点 `selling_point` | 一句话，≤ 40 字 | 必过 §3.3 四道闸 |
| 人群 `audience` | 谁 + 什么场景 + 什么痛点 | 必须含"身份"或"场景"，禁止只写"年轻人""宝妈" |

### 3.2 选填

| 字段 | 作用 |
|---|---|
| `product` 产品/品牌名 | 出现在信任段与 CTA |
| `offer` 价格/优惠 | CTA 的落脚点（"9.9 试三包"） |
| `platform` 平台 | 抖音 / 视频号 / 小红书 / 快手，影响语速档位与词库 |
| `tone` 语气 | 闺蜜 / 老板 / 测评 / 专业，影响人称与句长 |
| `banned_extra` 自定义禁词 | 品牌方自己的黑名单 |

### 3.3 卖点质量闸（产品角色的 gate）

四道闸，不过就打回，不进生成：

1. **单一性** —— 只能有 1 个核心卖点。出现"又便宜又好用又好看"直接打回。
2. **可验证** —— 必须带具体数字、材质、工艺或对比。禁止"品质好""性价比高"。
3. **场景性** —— 必须命中人群的一个具体时刻。"3 分钟煮好"命中"加班到十点的晚饭"。
4. **差异度** —— 不能是行业通用词。通用词 = 谁都能说 = 说了等于没说。

反例 → 正例：

| 打回 | 通过 |
|---|---|
| 我们的面很好吃，料很足 | 水开下锅 3 分钟，汤底是现熬的 |
| 性价比超高 | 一包 6 块 9，比外卖便宜 20 块 |
| 适合所有人群 | 给加班到十点、不想洗锅的独居白领 |

## 4. 输出契约

三段式，缺一不算交付：

1. **口播稿** —— 5 个段落，每段带 `[起-止 秒]` 与字数
2. **镜头提示** —— 恰好 3 条，覆盖全片时间轴
3. **禁用词检查** —— 结论 + 命中明细 + 替换建议

### 4.1 黄金样例 #1（对齐"什么叫可直接朗读"）

**输入**：卖点 = 水开下锅 3 分钟煮好一碗面；人群 = 加班到十点的独居白领

**口播稿**（全片 119 字 ≈ 27.1 秒 @ 4.4 字/秒）

| 段落 | 时间码 | 字数 | 台词 |
|---|---|---|---|
| 钩子 | 0:00–0:02.5 | 11 | 十点下班，你还煮得动面吗？ |
| 痛点 | 0:02.5–0:07.5 | 22 | 洗锅、烧水、等面熟，折腾四十分钟，最后你只想点外卖。 |
| 卖点 | 0:07.5–0:17.7 | 45 | 这包鲜煮面，水开下锅，三分钟捞出来就是一碗热汤面；面是锁鲜的，不是油炸的，汤底也配好了，你只负责烧壶水。 |
| 信任 | 0:17.7–0:23.2 | 24 | 配料表就六样，保质期四十五天；我连吃两周，第三周还想吃。 |
| CTA | 0:23.2–0:27.1 | 17 | 今晚别点外卖了，左下角拍一箱，先试三包。 |

**镜头提示**

| # | 时间码 | 景别/运镜 | 画面 | 字幕 |
|---|---|---|---|---|
| 1 | 0:00–0:09 | 中景，手持微晃 | 人物瘫在餐椅上，桌上堆着没洗的锅和外卖盒，手机屏还亮着工作群 | 十点下班 |
| 2 | 0:09–0:19 | 特写 + 俯拍，快剪 | 水开、下面、计时器跳 3:00、捞面入碗、热气糊住镜头 | 三分钟 |
| 3 | 0:19–0:27 | 中景推至产品特写 | 人物吃一口抬头，镜头推到包装与配料表，定格 CTA 文字 | 先试三包 |

**禁用词检查**

- 时长 27.1 s（区间 27–33）✅
- 结构：钩子 0–2.5 ✅ / CTA 23.2–27.1 ✅
- 极限词命中 0 ✅
- 备证提示 2 条：「连吃两周」属个人体验，须真实；「锁鲜」涉保鲜表述，建议留工艺依据
- 结论：可发布（带 2 条备证）

### 4.2 镜头提示字段

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 序号 / 时间码 | 必填 | 3 条首尾相接，无空档 |
| 景别 | 必填 | 特写 / 近景 / 中景 / 全景 |
| 运镜 | 必填 | 固定 / 推 / 拉 / 摇 / 跟 / 手持 |
| 画面内容 | 必填 | 一句话说清"镜头里有什么" |
| 动作 | 必填 | 人物在做什么，一个动词 |
| 字幕 | 必填 | ≤ 8 字，只放钩子词与价格 |
| 道具/场景 | 选填 | 拍摄前要准备的 |

### 4.3 检查报告字段

```
duration: 实测秒数 / 是否落在 27–33
structure: 钩子、CTA 是否存在且位置正确；5 段是否齐全
readability: 单句 > 20 字的句子清单；括号、英文缩写、书面语连接词
banned_hits: [{ word, level, segment, suggestion }]
conclusion: 可发布 / 需修改（附修改点）
```

## 5. 口径定义（先把尺子定死）

**30 秒 = 27–33 秒。** 不追点值，追区间。语速因人、因平台差 ±15%，报点值就是自欺。

**语速模型**：中文口播 4.0–5.0 字/秒，默认 4.4；每个标点 +0.15 s 停顿；阿拉伯数字按音节折算（"3 分钟"≈ 3 个音节）。字数 ÷ 语速 = 估算时长，同时输出下限（5.0 字/秒）与上限（4.0 字/秒）。

**钩子**：前 3 秒，必须满足以下之一——
- 身份点名："十点下班的"
- 反常识："别再煮面了"
- 损失感："你每月多花 600 块外卖钱"
- 提问："你还煮得动吗"

**CTA**：Call To Action，结尾 3–4 秒，**固定双落点**，缺一即判 A3 不合格：

1. **互动句** —— 把观众从"看完"推到"想说一句"（"别点外卖了""你也是这样吗"）
2. **行动句** —— 给一个具体、低门槛的动作（"左下角拍一箱，先试三包"）

两句合计 ≤ 17 字，必须落在同一段。互动先、行动后：先给情绪一个出口，再给手指一个去处。

**可直接朗读**（5 条硬规则）：
1. 单句 ≤ 20 字
2. 无括号、无注释、无"（笑）"
3. 无书面语连接词（"因此""综上所述""与此同时"）
4. 无生僻词与英文缩写
5. 念一遍不换气、不回头改口

## 6. 验收标准（全部可自动检测）

| # | 标准 | 阈值 | 检测方式 | 责任角色 |
|---|---|---|---|---|
| A1 | 时长 | 27–33 s | 字数 ÷ 语速 + 标点停顿 | 测试 |
| A2 | 钩子存在 | 前 3 s 内 | 段落时间码 + 四范式匹配 | 测试 |
| A3 | CTA 双落点 | 末段 ≤ 6 s，互动句 + 行动句齐全 | 段落时间码 + 句式匹配 | 测试 |
| A4 | 结构完整 | 5 段齐全 | 段落枚举 | 测试 |
| A5 | 可朗读 | 0 条违规 | 句长 / 符号 / 连接词规则 | 测试 |
| A6 | 禁词 | 0 命中高危 | 归一化后词库扫描 | 测试 |
| A7 | 镜头 | 恰好 3 条，时间轴无空档 | 区间并集 = 全片 | 测试 |
| A8 | 卖点单一 | 1 个核心卖点 | 产品闸四问 | 产品 |

A1–A8 全绿才算交付。任何一条红，回到对应角色，不带着问题往下走。

## 7. 分工映射

| 角色 | 在本工具里的落点 | 交付物 |
|---|---|---|
| 产品 | 输入卡 + 卖点四道闸 | `sellingPointGate()`：结构化提问 + 打回理由 |
| 研发 | 脚本骨架 + 语言填充 | 5 段结构、字数配额、句式模板、语气档位 |
| 测试 | 计时 + 合规 + 验收报告 | `checkDuration / checkStructure / scanBanned` |

## 8. 非目标（这一版不做）

- 不做分镜脚本、拍摄执行表、剪辑时间线
- 不做配音合成与数字人
- 不做多语言、多平台适配矩阵
- 不做账号数据回传与效果归因
- 不做长视频 / 直播话术

## 9. 风险与对策

| 风险 | 后果 | 对策 |
|---|---|---|
| 信息塞太多 | 超时、听不清 | 强制 1 卖点 + 2 支撑，第 3 个支撑直接砍 |
| 字数 ≠ 时长 | 交片对不上 | 报区间不报点值，输出 ±15% 上下限 |
| 极限词变体 | 漏检被限流 | 归一化：全角转半角、去空格符号、繁简、拼音变体 |
| 模板感重 | 千篇一律 | 3 个行业黄金样例 + 句式轮换池 |
| 卖点本身不合格 | 稿子再顺也没用 | 上游设闸，不合格不进生成 |

## 10. 已定稿决策（2026-10-31）

| # | 决策项 | 定稿 | 影响 |
|---|---|---|---|
| D1 | 交付形态 | **本地网页**（浏览器打开即用，单机运行，不上线） | M4 改为 Web 端，CLI 降级为内部调试入口 |
| D2 | 生成方式 | **接大模型**（OpenAI 兼容协议，baseURL / model / key 走配置） | 新增 LLM 适配层 + 提示词模板 + 失败降级 |
| D3 | CTA 口径 | **互动引导 + 下单行动，双落点都要** | 见 §5 CTA 定义，A3 按双落点判 |
| D4 | 禁用词范围 | 广告法 + 平台规则，294 条已入库 | 见 [禁用词库](禁用词库.md) |

### 连带影响

- **A6 的判定变了**：不再是"0 命中"，而是"0 条 `block`，`review` 需附举证提示"。像"纯天然""0 糖"这种禁不掉，得提示备证。
- **网页要能改稿**：模型出的稿子，人一定要能在页面上直接改字，改完实时重新计时和扫词。否则一次不满意就得重新生成，白瞎。
- **必须能离线演示**：模型挂了或没 key 时，用本地模板稿兜底，功能不中断——只标注"示例稿，非模型生成"。
