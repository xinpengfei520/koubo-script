# 任务拆分 · 卖点 → 30 秒口播稿

> 依赖：docs/需求梳理.md 的 §3 输入契约、§4 输出契约、§6 验收标准  
> 原则：先定契约，再写引擎，最后接壳。任何一层没验收，不进入下一层。

## 1. 架构一句话

```
输入卡 → 卖点闸 → 骨架生成（5 段 + 字数配额） → 语言填充
      → 三件套校验（计时/结构/禁词） → 定点重写 → 交付件
```

关键设计：**生成与校验分离**。生成器只管写，校验器只管判，重写只改被判红的那一段，不整篇重来。

## 3. 里程碑

| 里程碑 | 包含 | 交付形态 | 可演示 |
|---|---|---|---|
| **M1** | 契约 + 尺子 + 词库 | 能对任意脚本打分 | 给一段稿，输出时长/结构/禁词 |
| **M2** | 生成引擎 | 能出稿 | 给卖点人群，出 5 段稿 |
| **M3** | 三件套 | 能判稿 | 出稿自动带检查表 |
| **M4** | 出口 | 浏览器打开就能用 | 输卖点 → 出稿 → 改稿 → 导出，全链路 ≤ 30 秒 |
| **M5** | 回归 | 可信 | 黄金样例 + 边界不回归 |

建议节奏：M1 先跑通"打分"，因为校验器比生成器好验证——**先有尺子，再量东西**。

## 6. 测试策略

- **黄金样例**：样例 #1 全文快照，任何改动导致文本漂移必须显式确认
- **性质测试**：随机 200 组输入 → 输出必须满足 A1–A8，不许出现"生成成功但校验红"的漏网
- **对抗样本**：极限词 30 条变体（全角/拼音/拆字/加空格），召回率必须 100%
- **人工抽检**：每版抽 5 条稿，真人口念一遍计时，校准语速模型

| M5 回归 | 🟡 部分 | 黄金样例 + 变体冒烟已有；快照测试与对抗样本集未建 |

已实现的三个关键机制：

1. **定点重写**：只把不合格段落退回模型，合格段一字不动。
2. **降级链**：无 key / 超时 / JSON 解析失败 → 本地模板稿，界面标注。
3. **断连中止**：浏览器关掉就 abort 模型请求，不白烧 token；生成串行排队。

与计划的偏差：

- 用 ESM + JSDoc 而不是 TypeScript，省掉构建步骤，`node server.js` 直接跑。
- CLI（4.5）暂未做，调试用 `curl` 直接打 API。


## 9. v0.2（2026-10-31 晚）

用户验收后改了三件事：

1. **CTE → CTA**：术语修正为 Call To Action，双落点口径不变。
2. **看图写稿**：新增商品图上传，客户端压缩后走多模态消息；卖点可为空。
3. **润色**：单段 / 整篇两档，服务端按字数浮动 ≤ 10% 兜底，超差退回原稿。

实测：图片驱动生成 124 字 / 30 秒 / A1–A9 全绿；整篇润色 19.6 秒，字数 121，未触发退回。

## 10. v0.3（2026-10-31 晚）

新增拍摄模式：稿子底部「开始拍摄」→ 深色提词页 → 摄像头 → 录制 + 自动滚动。

- 独立页 `web/shoot.html`，sessionStorage 传稿，不动主页面状态
- MediaRecorder 录摄像头+麦克风，产出 webm，可直接下载
- 滚动距离 / 稿子估算时长 = 恒定语速，倍速可实时调
- 空格开始/停止，Esc 退出，控件半透明常驻（不挡操作）

踩过的三个坑：`[hidden]` 在独立页没生效导致遮罩挡住点击、提词层挡住了录制按钮、控件淡出后 pointer-events 让按钮点不到。
