# 禁用词库 v2026.10

> 数据文件：`data/banned.json`（294 条，7 级，三级处置）  
> 法条原文核对日期：2026-10-31

## 1. 先说结论：这不是一张黑名单

做口播稿检查，最容易犯的错是"拿一张极限词表做全文匹配"。结果两种：

- **漏**：黑名单永远不全，变体（拼音、拆字、全角）一扫就穿
- **误伤**：把"最后一天"里的"最后"、"我最近"里的"最近"全标红，稿子没法用

所以词库按**三级处置**组织，而不是"命中即死"：

| 处置 | 含义 | 典型词 |
|---|---|---|
| `block` | 直接禁用，必须换说法 | 最佳、国家级、根治、稳赚 |
| `review` | 不禁，但必须能举证，否则删 | 纯天然、0 糖、专利技术、销量领先 |
| `warn` | 高风险提示，人工判断 | 单字"最"、品类边缘表达 |

## 2. 法律依据（已核对原文）

主要落在《中华人民共和国广告法》这几条：

| 条款 | 内容 | 对应词库 |
|---|---|---|
| **第九条（三）** | 不得使用"国家级""最高级""最佳"等用语 | L1 全部 114 条 |
| **第十七条** | 除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用医疗用语 | L2 功效词 |
| **第十六条** | 医疗、药品、医疗器械广告不得表示功效、安全性的断言或保证，不得说明治愈率、有效率 | L2 医疗类 |
| **第十八条** | 保健食品广告不得涉及疾病预防、治疗功能，不得与药品比较，须标明"本品不能代替药物" | L7 保健 |
| **第二十条** | 禁止发布声称全部或部分替代母乳的婴儿乳制品广告 | L7 母婴 |
| **第二十四条** | 教育培训不得对升学、通过考试作保证性承诺，不得暗示命题人员参与 | L7 教育 |
| **第二十五条** | 投资回报类广告不得明示或暗示保本、无风险、保收益 | L3 金融 |
| **第二十六条** | 房地产广告不得含升值或投资回报承诺 | L7 房产 |
| **第二十八条** | 虚假广告的五种情形（含虚构使用效果） | L4 虚假 |
| **第五十七条** | 违反第九条的罚则：**20 万–100 万元**，情节严重吊销营业执照 | 为什么 L1 必须 block |

原文来源：临海市政府网转载《中华人民共和国广告法》（2021 修正） <http://www.linhai.gov.cn/art/2021/1/12/art_1229482632_59004180.html>；权威版本以国家法律法规数据库 <https://flk.npc.gov.cn/> 为准。

平台侧规则（抖音/小红书/快手）另有一套，主要管**导流、诱导互动、诱导交易**，处置是限流/下架/扣分，不是罚款。这两套要分开判，别混成一个"违禁词"。

| 级别 | 名称 | 条数 | 处置 | 说明 |
|---|---|---|---|---|

每条记录带 `scope` 字段（`all` / `food` / `health` / `fintech` / `douyin`…），选品类和平台时自动收窄范围。卖面条的不该被"根治"以外的东西打扰，卖保健品的必须叠加 L7。

## 4. 三个真实的误伤坑

**坑一：单字"最"**
"最后""最近""最初""最终"是正常词；"最怕加班""最想下班"是情绪，不是商品极值。词库因此**不收录裸"最"**，只收复合词（最好/最佳/最强…），另设 `single_char_audit`：白名单和情绪词剔除后仍剩下"最"，才标 L1-low 交人工复核。

**坑二："第一"**
"第一次""第一步""第一口"是序数，不是排名。进白名单。真正的雷是"销量第一""行业第一"——这类必须带统计口径和出处，否则按 L1 处理。

**坑三："最新" vs "最近"**
"最新款"是绝对化（没有最新，只有更新），禁；"最近"是时间，不禁。一字之差，规则要写死。

## 5. 扫描流程

```
原文
 ├─ 1. 归一化：全角→半角、去空格与零宽字符、繁→简、
 │            数字符号归一（NO.1 / ＮＯ．１ / 第1 → 第一）、
 │            拼音谐音展开（zui / 蕞 / 冣）、英文展开（yyds）
 ├─ 2. 最长匹配：先匹配"全网最低价"，不再重复报"最低价"
 ├─ 3. 白名单：最后/最近/第一次/最怕… 命中即跳过
 ├─ 4. 分级打标：L1–L7 + block/review/warn
 ├─ 5. 生成替换：取该条 replace 字段，结合上下文改写
 └─ 6. 输出：词 / 级别 / 段落 / 原句 / 建议 / 依据条款
```

第 2 步很关键。不做最长匹配，一句话能报出五条重复告警，人就不看了。

## 6. 局限（必须写清楚）

- **不是法律意见**。词库能挡住 80% 的明雷，挡不住"暗示性表述"——"用了它，我三年没感冒"这种，机器判不了，得人看。
- **平台规则会变**。抖音的导流口径一年能改两版，L5 建议每季度对一次官方规则中心。
- **语境决定性质**。"这个价格我闭眼入"是口播常用表达，但带货场景会被判诱导。同词不同命，这也是为什么要有 `review` 档。
- **特殊品类必须叠加**。卖保健食品只扫通用词库是不够的，L7 必须一起开。

## 7. 维护

- `version` 字段跟日期走，每次改动在文末记变更
- 新增词必须带：级别、依据条款、处置、至少 1 条替换建议
- 回归测试：30 条变体样本（全角/拼音/拆字/加空格），召回率必须 100%
